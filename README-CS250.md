How do I interpret user needs and implement them into a program? How does creating “user stories” help with this?

    - User needs are features of an application or program that a user requires for the program to be considered complete. 
      These features should perform certain actions or allow certain actions by the user within the application. 
      Creating user stories helps with this by providing a backlog that helps maintain focus, organization, and clarification of
      program requirements.

How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

    - I approach developing programs by identifying a general premise with general requirements while keeping in mind that
      these requirements may change or that requirements may be added. Some Agile processes I hope to incorporate in future work,
      and actually do incorporate in personal projects, are creating user stories/ features, maintaining a refined backlog, 
      and performing sprint retrospectives.

What does it mean to be a good team member in software development?

    - What it means to be a good team member in software development is to be diligent and thorough in your work, as well as being earnest.
      Maintaining communication is key to being a good team member; communication is paramount to a functioning team. Lastly, maintaining focus
      on the active project and working with others to clear impediments to the project's completion should remain at the top of priorities while
      working within a team.
